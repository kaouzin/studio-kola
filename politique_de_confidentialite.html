Studio Kola – Privacy Policy

Last updated: October 30, 2026

Studio Kola is a private desktop tool used only by its owner, Kola Konipo, to upload videos he creates to his own YouTube channel (“ANKA MALIBA”). It is not offered to the public and has no other users.

Data accessed through YouTube API Services

Studio Kola uses YouTube API Services. With the owner’s explicit authorization (Google OAuth), it accesses:

  • the ability to upload videos and set their title, description, tags, category, language and privacy status (scope youtube.upload);
  • the name of the authorized channel, only to confirm which channel is connected (scope youtube.readonly).

Studio Kola does not access, collect or store any data about viewers, comments, subscribers or any other YouTube user.

How data is used, stored and shared

  • The OAuth token is stored only on the owner’s own computer and is used only to upload the owner’s videos to the owner’s channel.
  • No data is sold, shared with third parties, or used for advertising or analytics.
  • No personal data is sent to any server operated by Studio Kola (there is none).

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://myaccount.google.com/permissions. Deleting the local token file removes all stored authorization data immediately; in any case, stored authorization data is deleted within 7 days of revocation.

Google and YouTube policies

By using Studio Kola you agree to the YouTube Terms of Service: https://www.youtube.com/t/terms. Google’s Privacy Policy applies to data processed by Google: https://policies.google.com/privacy.
